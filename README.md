# Anlin (Napert) Li — Personal Academic Website

Minimal academic personal website prepared for GitHub Pages.

## Target address

`https://nptl1201.github.io/`

For a GitHub user site, create a **public** repository named exactly:

`NPTL1201.github.io`

Place all files from this folder at the repository root. GitHub Pages will serve the site at the address above.

## Search indexing

The site includes:

- canonical URL
- index/follow metadata
- Open Graph metadata
- Schema.org Person structured data
- `robots.txt`
- `sitemap.xml`

After the site is live, add `https://nptl1201.github.io/` to Google Search Console and request indexing. Indexing timing is controlled by search engines and may take time.
